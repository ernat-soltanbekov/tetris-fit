# Результаты проверки

Локальный прогон: 1 октября 2026 года, macOS / arm64, Apple M4, Go 1.27.1.
Это наблюдения конкретного прогона, а не обещание одинакового времени на другом
компьютере. Linux и совместимость с Go 1.25 дополнительно проверяет GitHub Actions.
Текущее состояние CI доступно через значок в README.

## Официальные примеры

Измерения сохранены машинно в [`audit-results.json`](audit-results.json).
Все фигуры проверены по буквам и координатам, разрешены только переносы и повороты.

Время полного запуска включает создание процесса и системные расходы; оно
измерено отдельно от `time.Since` внутри решателя. Все случаи укладываются
в 10 секунд. Внешний аудиторский скрипт принудительно ограничивает каждый процесс
этим временем. Шесть ошибочных файлов дают точно `ERROR\n` и ненулевой код
в обычном режиме, с `--analyze` и с `--visualize`.

SHA-256 всех 11 официальных входных файлов совпали с манифестом скачивания.

## Автоматические проверки

Успешно выполнены `gofmt`, `go vet ./...`, `go test -race -coverprofile=coverage.out ./...`,
сборка обеих команд и `python3 scripts/audit.py`.

| Пакет | Покрытие statements |
| --- | --- |
| analyzer | 97.5% |
| cli | 93.3% |
| parser | 97.7% |
| solver | 97.8% |
| tetromino | 100.0% |
| visualizer | 100.0% |

Файлы `cmd/*/main.go` имеют 0% модульного покрытия: их запуск проверяется отдельно
через готовые исполняемые файлы. Покрытие не является доказательством отсутствия
ошибок; для минимальности используется независимый перебор, для контракта CLI —
независимая проверка результата на Python.

- 842 сравнения с простым точным решателем: 722 пары в двух режимах и 120 наборов
  из трёх или четырёх фигур. Размеры совпали, фигуры сохранились.
- 24 параллельных вызова решателя под race detector прошли без обнаруженных гонок.
- 32 процесса, запускаемые с параллелизмом 8, вернули корректный одинаковый результат.
- Максимальные входы: 26 O и 26 фиксированных I требуют 12×12, содержат 104
  заполненные и 40 пустых клеток. Буквы A…Z сохранены.
- Плохие аргументы, ограничение чтения, ошибки reader/writer, FIFO, таймаут,
  отмена поиска и ограничение числа попыток обработаны ожидаемым образом.
- Для смешанных наборов 8–26 фигур проверяется либо корректное решение, либо
  честная остановка на бюджете 50 000 проверок. Эти случаи не все обязаны решаться
  в заданном бюджете; завершённость поиска не подменяется наличием частичной доски.
- Прогон fuzzing парсера: 1 782 958 выполнений, ошибок не найдено.
- Прогон fuzzing пар фигур: 664 030 выполнений, расхождений с oracle не найдено.
  Каждый fuzz-тест запускался с `-fuzztime=10s -parallel=2`; это число выполнений,
  а не число уникальных входов. CI повторяет fuzzing для каждой версии Go.

## Что проверки не устанавливают

Нет обещания завершить точную упаковку любых 26 фигур за 10 секунд.
Таймаут предотвращает неограниченный вычислительный поиск, но не превращает
его в найденное решение. Fuzzing и тесты не являются формальным доказательством
всей реализации. Устное объяснение и живое предсказание результата на аудите
остаются отдельной проверкой понимания автора.
